Employee MIS Dashboard – Excel Project

Project Overview

This project is an Employee Management Information System (MIS) Dashboard created using Microsoft Excel.

It summarizes employee data and presents key information through KPI cards, summary tables, and charts. The dataset has been anonymized for public portfolio use.

Project Objectives

- Analyze employee distribution across departments.
- Calculate total and average salary.
- Summarize employee performance ratings.
- Analyze attendance status.
- Present important information in a dashboard.

Excel Skills Used

- Data cleaning using "TRIM"
- Conditional calculations using "COUNTIF", "SUMIF", and "AVERAGEIF"
- Data summarization
- KPI creation
- Chart creation
- Number and currency formatting
- Dashboard layout and presentation
